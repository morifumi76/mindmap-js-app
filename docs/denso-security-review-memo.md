# セキュリティ確認メモ：マインドマップ（オフライン配布版 `local.html`）

提出先：株式会社デンソー 御中
作成：ジョウホウソース株式会社
対象ファイル：`local.html`（単一HTMLファイル）
バージョン：v2.2.2（2026-06-28 ビルド）

---

## 結論

本ファイル `local.html` は、**外部と一切通信しない、完全に自己完結した単一HTMLファイル**です。
インターネット接続がない環境（機内モード／オフライン）でも全機能が動作します。

---

## 1. 外部通信について

- 開いた時点で発生する外部ネットワーク通信：**ゼロ**
- 外部サーバーへのデータ送信：**なし**
- 解析・トラッキング（Google Analytics / gtag 等）：**一切含まない**
- 外部CDN・外部フォント・外部スクリプトの読み込み：**なし**（すべてファイル内に内蔵）

## 2. データの保存先

- 利用者が作成したマインドマップは、**利用者自身のブラウザ内（localStorage）にのみ**保存されます。
- 外部のクラウドやサーバーには送信・保存されません。
- バックアップは「JSONバックアップ」ボタンで、**利用者のPC内にファイルとしてダウンロード**する方式です（通信は発生しません）。

## 3. ファイル内に埋め込まれているもの（すべて自己完結）

| 種類 | 状態 |
|---|---|
| アプリ本体のプログラム（JavaScript） | ファイル内に内蔵 |
| 画面デザイン（CSS） | ファイル内に内蔵 |
| アイコン（favicon） | 画像をファイル内に埋め込み（`data:` 形式） |
| `http://www.w3.org/2000/svg` の記載 | 図形（SVG）の記述ルールを示す**識別子**であり、通信先ではありません |

## 4. 確認方法（第三者が再現可能）

1. PCをオフライン（機内モード）にする
2. `local.html` をブラウザで開く → すべての機能が問題なく動作する
3. ブラウザの開発者ツール（F12）→「ネットワーク（Network）」タブを開いた状態でページを再読み込み
   → **外部ドメインへの通信が1件も発生しない**ことを確認できる

## 5. 補足

- 本ファイルのソースコード内には、別バージョン（クラウド版）と共通の枠組みに由来する
  クラウド保存用の分岐コード（`if (window._supa) …`）が一部残っていますが、
  本ファイルではその接続オブジェクト（`window._supa`）を**一切生成していない**ため、
  これらの分岐は**永久に実行されず、通信は発生しません**。
- クラウド連携を行う別バージョン（要ログイン）とは**別物**であり、本ファイル単体では
  ログイン・同期・共有などの外部通信機能は動作しません。
