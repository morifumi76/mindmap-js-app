# ジョウホウソースマインドマップ（ローカル版）README

> このファイルは、ローカル版（`dist/local.html`）をエンドユーザーへ配布する際に同梱する説明書です。
> 配布時は `local.html` と一緒にこの内容（テキスト/PDF など）を渡してください。

このファイルは、インターネットに一切接続せず、お使いのパソコンの中だけで動くマインドマップです。
社外にデータを送らないので、高セキュリティな環境でも安心してお使いいただけます。

--------------------------------------------------

## 1. これは何？

- 「local.html」という 1 つのファイルだけで動くマインドマップアプリです。
- 外部のサーバーやクラウドと通信しません。入力した内容が外に送られることはありません。
- ログイン不要。ファイルを開いたらすぐ使えます。

## 2. 置き場所（おすすめ）

- ダウンロードした「local.html」は、自分のパソコンの分かりやすい固定の場所に置いてください。
  - 例：ドキュメント\マインドマップ\local.html
  - または、デスクトップに専用フォルダを作ってその中に入れる
- USB メモリやネットワーク共有フォルダから「直接」開くより、いったん自分の PC のローカルフォルダにコピーしてから使う方が安定します。
- ★重要：一度使い始めたら、ファイルを別の場所に移動したり、名前を変えたりしないのがおすすめです（自動保存したデータが見えなくなる場合があります）。

## 3. 使い方

1. 「local.html」をダブルクリックします。
2. いつものブラウザ（Chrome / Edge / Safari など）で開きます。
3. あとは通常のマインドマップと同じように使えます。

## 4. データはどこに保存される？

- 編集した内容は、開いたブラウザの中（このパソコンの中）に自動保存されます。
- 次に「同じパソコンの同じブラウザ」で開くと、前回の続きが自動で復元されます。
- ★データはこの HTML ファイルの中には入っていません。
  「HTML ＝ 道具」「データ ＝ ブラウザの中」と別々に管理されています。
  そのため、HTML ファイルを誰かに渡しても、あなたのデータは一緒には渡りません。

## 5. バックアップ・持ち運び（JSON）

- 画面の「JSON バックアップ」から、データを 1 つのファイル
  （例：mindmap-backup-YYYYMMDD.json）として書き出せます。
- 次のようなときは、この JSON ファイルを使ってください。
  - 別のパソコンにデータを移したいとき
  - 念のためのバックアップを取りたいとき
- 移行先では、書き出した JSON ファイルを読み込めば、データを復元できます。
  読み込み方法は「local.html を開いた画面（ブラウザのウィンドウ）に、JSON ファイルを
  ドラッグ＆ドロップ」です（詳しい手順は「7. バージョンと更新について」を参照）。

## 6. 注意点

- ブラウザの「閲覧履歴・サイトデータの削除」を行うと、自動保存したデータも消えることがあります。
  大事なマップは、定期的に「JSON バックアップ」で保存しておくと安心です。
- 別のパソコン・別のブラウザで開くと、それぞれ別の保存場所になります（自動では共有されません）。
- シークレット／プライベートモードで開くと、閉じたときにデータが消えることがあります。通常モードでお使いください。

## 7. バージョンと更新について

- 画面の左下にバージョン（例：v1.0.0（配布日））が表示されます。
- このローカル版は「自動更新されません」。
  新しい版が出たら、配布元から新しい「local.html」をダウンロードして差し替えてください。

- 差し替えのときもデータは引き継げます。
  ＜基本＞ 同じパソコン・同じブラウザで、同じ場所に置いて新しい「local.html」を開けば、
          これまでのデータは自動でそのまま引き継がれます（特別な操作は不要です）。

  ＜念のため・うまく引き継げないとき＞ JSON バックアップで確実に移せます。
  1. 古い版で「JSON バックアップ」を書き出す（mindmap-backup-YYYYMMDD.json）
  2. 新しい「local.html」をダブルクリックして開く（ブラウザに画面が表示されます）
  3. 書き出した JSON ファイルを、その「開いた画面（ブラウザのウィンドウ）」の上に
     ドラッグ＆ドロップする
  4. 「読み込みますか？」と確認が出たら OK。読み込み後に自動で表示し直されます

  ★ここに注意：JSON は「ブラウザで開いた画面」に落としてください。
    Finder（デスクトップ）上の「local.html のファイルアイコン」に重ねても読み込めません。
    （アイコンではなく、開いた後の画面にドロップ、と覚えてください）
